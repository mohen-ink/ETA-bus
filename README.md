# 秒查公交

一款简洁的实时公交查询 App：打开就能看到附近站点和车辆还有几站、几分钟到站。

## 下载安装

1. 前往 [Releases](https://github.com/mohen-ink/ETA-bus/releases) 页面，下载最新版本的 `ETA-bus-版本号-arm64-v8a.apk`。
2. 在手机上打开下载的文件进行安装。如果系统提示「禁止安装未知来源应用」，按提示允许本次安装即可。
3. 支持 Android 8.0 及以上、64 位 ARM 处理器的手机（近几年的主流手机都可以）。

## 首次使用

1. 打开 App 后会弹出隐私说明，点击「同意并继续」。
2. 按系统提示允许定位权限，首页会自动显示你附近的公交站。
3. 如果不想授权定位，也可以在「设置 → 手动设置位置」输入经纬度，或者直接搜索线路和站点。

## 查看附近站点

- 首页「附近」列表按距离从近到远排列，离你最近的站点会直接展示各线路的到站情况。
- 其他站点点击「查看到站」即可展开；点击站名进入站点详情。
- 下拉列表或点击右上角的定位图标可以重新定位并刷新。
- 点击右上角的地图图标，可以在地图上查看周边站点；拖动地图后点击「搜索此区域」查看别处的站点。

## 看车还有多久到

每条线路右侧会显示到站信息：

| 显示 | 含义 |
|---|---|
| **3站** · 5分钟 · 1.2公里 | 最近一辆车还有 3 站，预计 5 分钟，距离 1.2 公里 |
| **即将到站** / **已到站** | 车马上到或已经到了 |
| **等待发车** | 车还在起点站，可能会显示计划发车时间 |
| **非运营时间** / **已过末班** | 当前没有车，会显示首末班时间 |

## 站点详情

- 列出经过该站的全部线路及到站信息。
- 同一个站名通常有两个站台（马路两边，方向不同），点击「切换站台」查看另一边。
- 点击右上角星标收藏该站点。

## 线路详情

点击任意一条线路进入：

- **第一辆 / 第二辆**：同时显示最近两辆车的到站情况。第二辆车的时间根据车辆实时位置估算，仅供参考。
- **站点条**：横向展示整条线路的所有站点，巴士图标表示车辆当前的位置。左右滑动查看，点击任意站点可以把它设为等车站。
- **切换等车站**：点击顶部的站名，从列表中选择你要上车的站。
- **选择下车站**：选好后会显示一共要坐几站。
- **换向**：点击标题栏右上角的双向箭头，查看反方向的线路。
- **首末班与票价**：点击线路名下方的那一行查看详情。
- **线路地图**：展开后可以在地图上查看整条线路和车辆位置。
- 点击右上角星标收藏「这条线路 + 这个等车站」，以后在收藏页直接看到站时间。

## 搜索

点击首页顶部的搜索框，可以：

- 输入线路号（如 `5路`、`35`）查找线路，上下行会分别列出；
- 输入站名（如 `红卫`）查找站点及经过的线路。

最近的搜索记录会保存在搜索页，方便再次查询。

## 收藏

- 底部导航「收藏」页分为「线路」和「站点」两栏，直接显示实时到站信息。
- 长按右侧的拖动图标可以调整顺序。
- 向左滑动可删除单条收藏，删除后可点击「撤销」恢复；点击「编辑」可批量删除。

## 历史

首页切换到「历史」可以看到最近浏览过的线路和站点。向左滑动删除单条，点击「清空」删除全部。

## 切换城市

点击首页左上角的城市名，可以按名称、区号或首字母搜索，切换到其他城市。收藏和历史按城市分别保存。

## 设置

| 设置项 | 说明 |
|---|---|
| 当前城市 | 切换所在城市 |
| 附近范围 | 首页搜索附近站点的范围：500 米 / 1000 米 / 3000 米 |
| 自动刷新 | 页面停留时自动更新到站信息的间隔：15 秒 / 30 秒 / 60 秒 / 关闭 |
| 手动设置位置 | 不使用定位时，手动输入所在位置的经纬度 |
| 深色模式 | 跟随系统 / 浅色 / 深色 |
| 清除数据 | 清除当前城市的浏览历史、收藏，或清除搜索记录 |

## 常见问题

**附近没有显示站点？**
确认已开启定位权限和手机定位开关，然后下拉刷新。也可以在设置里把附近范围调大。

**显示「暂无数据」或「未更新」？**
通常是网络不稳定，点击「重试」或下拉刷新即可。

**到站时间和实际有出入？**
到站信息来自公交平台的实时数据，受路况影响可能有偏差，请以实际运营为准。

## 说明

- 公交数据来自掌上公交，地图与定位由高德地图提供。
- 设置、收藏和浏览历史只保存在你的手机上。
